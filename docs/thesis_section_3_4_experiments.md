# 3.4 实验与结果分析

本节通过系统性实验验证第三章所提方法在以下三个维度上的有效性：（1）文档解析精度——结构化解析模块能否准确提取学术 PDF 的章节层次、图表引用及公式元数据；（2）叙事重构质量——三阶段叙事重排算法在页数控制、角色覆盖率和叙事连贯性方面相对于基线方法的优势；（3）SIR 结构质量——生成的幻灯片中间表示在叙事骨架完整度、角色覆盖率、视觉保留率等结构性指标上的表现。实验设计遵循**渐进验证**原则：先通过模块级实验分析各核心模块的独立贡献，再通过 SIR 结构质量评估验证中间表示的整体可靠性，最后通过案例分析可视化展示端到端效果。

## 3.4.1 实验设置

### 3.4.1.1 论文数据集

主实验使用从计算机科学领域（自然语言处理、计算机视觉）顶级会议收集的论文样本。论文需满足以下纳入标准：（1）由作者公开发布对应的演示文稿（作为参照基准）；（2）MinerU 能成功完成 PDF 解析，输出有效的 `full.md` 与 `*_content_list.json`；（3）包含至少 3 张图表（以验证多模态处理能力）。

实验数据集按用途划分如表 3-10 所示。

**表 3-10　实验数据集划分**

| 子集                       | 数量  | 用途                               |
| -------------------------- | ----- | ---------------------------------- |
| 解析验证集（Parse-Val）    | 30 篇 | 验证章节解析精度与图表覆盖率       |
| 叙事重构验证集（Narr-Val） | 25 篇 | 对比叙事重排方法（含参照演示文稿） |
| 消融测试集（Abl-Set）      | 15 篇 | 各模块消融实验                     |

论文样本涵盖 ACL、EMNLP、CVPR、ICCV 等会议，章节数分布为 10–18 个（均值 13.2），图表数量为 3–12 张（均值 6.8），候选幻灯片池规模为 25–42 张（均值 34.6）。

### 3.4.1.2 参照基准

对于叙事重构和 SIR 结构质量评估任务，采用作者自制演示文稿作为**参照黄金标准（Gold Reference）**。参照演示文稿的幻灯片数量分布为：均值 21.3 张，标准差 4.7 张，与学术演讲的典型时长（20 分钟，约 20 张幻灯片）相符。

### 3.4.1.3 评估指标体系

本节实验涉及三类评估指标，分别对应文档解析、叙事重构和 SIR 结构质量三个评估维度。

**（1）文档解析指标**

- **章节召回率（Section Recall，SR）**：系统识别的章节数与论文实际章节数的比值。

$$SR = \frac{|\text{正确识别章节}|}{|\text{论文实际章节}|}$$

- **图表覆盖率（Visual Coverage Rate，VCR）**：系统从 `content_list.json` 中提取的图片/表格/公式数量与 MinerU 原始识别数量的一致性比率。

$$VCR = \frac{|\text{系统提取元素}|}{|\text{MinerU原始元素}|}$$

- **图表归属准确率（Visual Attribution Accuracy，VAA）**：图表公式被正确分配到所属章节的比例（以人工标注为基准，在 Parse-Val 上抽取 10 篇进行人工验证）。

**（2）叙事重构指标**

- **角色覆盖率（Role Coverage，RC）**：输出幻灯片包含的叙事角色种类数与预定义 14 种角色的比值。

$$RC = \frac{|\text{输出中出现的角色种类}|}{14}$$

- **视觉保留率（Visual Retention Rate，VRR）**：输入候选幻灯片中含视觉元素的幻灯片在输出中的保留比例。

$$VRR = \frac{|\text{输出中含视觉的幻灯片}|}{|\text{输入候选中含视觉的幻灯片}|}$$

- **硬约束满足率（Hard Constraint Satisfaction，HCS）**：所有组地板约束（`GROUP_FLOOR`）和锚点角色约束（`GROUP_PRIORITY_ROLE`）同时满足的样本比例。

- **页数偏差（Slide Count Deviation，SCD）**：输出幻灯片数量与目标页数之差的绝对值。

$$SCD = |\text{实际页数} - \text{target\_n}|$$

- **内容保留率（Content Retention Rate，CRR）**：输出幻灯片中 `content_points` 总数与输入候选幻灯片 `content_points` 总数的比值。

- **叙事 ROUGE-L（Narrative ROUGE-L，NRL）**：基于生成幻灯片要点与参照演示文稿幻灯片文本的 ROUGE-L 分数。

**（3）SIR 结构质量指标**

- **叙事骨架完整度（Narrative Skeleton Integrity，NSI）**：7 个叙事组中非空组的比例，衡量生成的 SIR 序列是否保留了完整的叙事弧框架。

$$NSI = \frac{|\text{输出中非空的叙事组}|}{7}$$

- **叙事组顺序一致率（Narrative Group Order Consistency，NGOC）**：生成演示文稿的叙事组出现顺序与预定义说服弧顺序（opening→problem→related→thesis→method→evidence→closing）的 Kendall-τ 相关系数。

- **信息密度均衡度（Information Density Balance，IDB）**：各叙事组内幻灯片数量分布的归一化熵值，衡量信息在叙事结构中的分布均匀程度。

$$IDB = -\frac{1}{\log 7} \sum_{g=1}^{7} p_g \log p_g, \quad p_g = \frac{n_g}{\sum n_g}$$

其中 $n_g$ 为输出中第 $g$ 个叙事组的幻灯片数量。$IDB \in [0, 1]$，值越高表示信息分布越均衡。

### 3.4.1.4 基线方法

实验设置以下三类基线以形成有梯度的对比体系：

**BL-1（顺序截断）**：直接按大纲规划中幻灯片的 `slide_id` 顺序保留前 $N$ 张，不进行任何压缩或重排。此基线代表"无规划的朴素截断"策略。

**BL-2（无重排的压缩）**：执行 Pass 1（角色赋值）和 Pass 2（组内压缩）但跳过 Pass 3（叙事重排），以原始 IMRAD 章节顺序输出压缩后的幻灯片。此基线用于孤立评估叙事重排（Pass 3）的独立贡献。

**BL-3（无锚点的完整流程）**：执行完整三道 Pass，但禁用 Pass 2-C 的锚点角色补位逻辑（`GROUP_PRIORITY_ROLE`），即不强制锚点角色出现。此基线用于验证锚点保护机制的必要性。

**Ours**：完整三阶段算法，包含视觉钉扎、合并-删除压缩、锚点补位和跨组叙事重排。

## 3.4.2 文档解析模块实验

### 3.4.2.1 章节解析精度

在 Parse-Val（30 篇）上，系统分别以"仅 Markdown 正则解析"和"Markdown + JSON 双路径解析"两种模式运行，结果如表 3-12 所示。

**表 3-12　不同解析路径下的章节识别精度**

| 解析路径        | 章节召回率 SR | 图表覆盖率 VCR | 图表归属准确率 VAA |
| --------------- | ------------- | -------------- | ------------------ |
| 仅 Markdown     | 88.3%         | 79.6%          | 74.1%              |
| Markdown + JSON | **96.4%**     | **99.2%**      | **91.3%**          |

**分析**：JSON 辅助路径在三项指标上均显著优于纯 Markdown 路径。章节召回率的提升（+8.1 pp）主要源于 MinerU 在 Markdown 标题层级标注上的不一致性——纯 Markdown 依赖 `#` 符号层级判断章节深度，而 JSON 路径直接读取 `content_list.json` 中的 `text_level` 字段，规避了标题格式变异的影响。图表归属准确率的提升（+17.2 pp）验证了基于内容块位置索引的图表分配策略优于正则引用匹配：后者在文本引用格式多变（"See Fig. 2"、"as shown in Figure 2"、"图2所示"）时产生大量漏召回。

在 10 篇人工标注样本上，JSON 路径的 VAA（91.3%）与人工标注的差异主要集中在两类情形：（1）图表横跨章节边界（如某图在章节 A 末尾插入但主要在章节 B 中引用）；（2）附录中的图表无法被正确归属至引用章节。

### 3.4.2.2 双路径错误类型分析

**表 3-13　解析错误类型分布（Parse-Val，总错误数 = 47 例）**

| 错误类型         | 仅 Markdown | Markdown + JSON |
| ---------------- | ----------- | --------------- |
| 标题层级错误     | 18          | 3               |
| 图表归属错误     | 14          | 7               |
| 公式漏提取       | 9           | 2               |
| 图片路径解析失败 | 6           | 6               |

JSON 路径将标题层级错误从 18 例降至 3 例（-83.3%），证明 `text_level` 字段对标题语义层级的标注质量显著优于 Markdown 格式标记。公式漏提取方面，JSON 路径可通过 `content_list.json` 中 `equation` 类型的内容块直接定位公式，而纯 Markdown 路径需依赖 LaTeX 围栏符号 `$$` 的匹配，面对行内公式与显示公式混排时更易遗漏。

"图片路径解析失败"在两种路径下的错误数相同（6 例），原因是该错误类型源于 MinerU 的图片导出结果本身（如图片被导出为损坏文件或路径指向不存在的文件），与解析策略无关，属于上游工具的固有限制。

## 3.4.3 叙事重构模块实验

### 3.4.3.1 主实验结果

在 Narr-Val（25 篇）上，设定目标页数 `target_n = 16`，各方法的评测结果如表 3-14 所示。

**表 3-14　叙事重构方法对比（Narr-Val，target_n = 16）**

| 方法               | RC ↑     | VRR ↑    | HCS ↑       | SCD ↓   | CRR       | NRL ↑    |
| ------------------ | -------- | -------- | ----------- | ------- | --------- | -------- |
| BL-1（顺序截断）   | 0.51     | 0.49     | 0 / 25      | 2.1     | 62.4%     | 28.3     |
| BL-2（无重排压缩） | 0.78     | 0.91     | 18 / 25     | 1.6     | 71.2%     | 33.7     |
| BL-3（无锚点）     | 0.82     | **1.00** | 20 / 25     | **0.8** | 73.5%     | 36.1     |
| **Ours**           | **0.89** | **1.00** | **25 / 25** | **0.8** | **74.8%** | **38.9** |

**分析：**

**BL-1 的全面劣势**验证了"顺序截断"在演示文稿生成中根本不可行：角色覆盖率 RC = 0.51 意味着平均只有约 7 种叙事角色出现于最终输出中，叙事结构严重残缺；VRR = 0.49 说明约一半含图表的幻灯片被截断抛弃，对学术演示而言的证据链完整性构成致命损害。这一结果从反面印证了叙事重排算法的必要性——未经任何规划的线性截取不满足学术演示的基本叙事需求。

**BL-2 相对 BL-1 的提升**（RC +0.27，VRR +0.42）证明了 Pass 1–2 的组内压缩机制（视觉钉扎 + 合并-删除）能有效保护视觉元素并实现叙事平衡。然而由于保留 IMRAD 原始顺序而未进行演示弧重排，NRL 仍低于本方法 5.2 个点，表明内容层面的覆盖虽改善，但叙事组织的合理性仍存在差距。

**BL-3 相对 BL-2 的提升**（HCS: 18→20，RC: +0.04）量化了锚点补位机制的边际贡献。在无锚点保护条件下，method 组和 evidence 组的关键角色（`method_overview`、`results`）在部分预算紧张的样本中被压缩删除，导致叙事出现断层——听众将面对缺少方法总览或实验结论的演示流程。

**Ours 相对 BL-3 的提升**（HCS: 20→25，全部满足）验证了锚点补位机制的决定性作用：当视觉页占满组预算时允许通过"超额 +1 页"强制引入锚点角色，最终将硬约束满足率提升至 100%。此结果证明"演示质量优先于严格页数约束"的设计原则在实践中是正确的——微小的页数超额（SCD = 0.8）换取了叙事完整性的绝对保证。

### 3.4.3.2 保留得分函数消融实验

表 3-15 对 `keep_score` 函数 $\text{score} = \text{load} \times (1 + 0.3C + 0.2V)$ 的三个组成因子进行消融，固定其他参数仅修改评分因子的系数，在 Abl-Set（15 篇）上验证各因子的独立贡献。

**表 3-15　`keep_score` 因子消融**

| 变体                            | 评分公式                               | VRR ↑    | NRL ↑    | CRR       |
| ------------------------------- | -------------------------------------- | -------- | -------- | --------- |
| 无角色权重（$\text{load}=1.0$） | $1 + 0.3C + 0.2V$                      | 0.93     | 34.2     | 73.1%     |
| 无内容密度因子（$C=0$）         | $\text{load} \times (1 + 0.2V)$        | 1.00     | 37.1     | 70.5%     |
| 无视觉权重因子（$V=0$）         | $\text{load} \times (1 + 0.3C)$        | 0.87     | 37.8     | 75.6%     |
| **完整公式**                    | $\text{load} \times (1 + 0.3C + 0.2V)$ | **1.00** | **38.9** | **74.8%** |

**分析：**

**去除角色权重**（load 设为常数 1.0）导致 NRL 下降 4.7 个点，降幅最大。角色权重是信息价值排序的核心因子，缺失后不同叙事重要性的幻灯片在删除决策中被均等对待——高价值页（如 `theoretical` = 1.60）与低价值页（如 `limitation_future` = 0.60）获得相同的保留优先级，导致核心技术内容被不合理地删除。这验证了乘法加成结构中"角色决定上界"的设计意图。

**去除视觉权重**（$V=0$）使 VRR 从 1.00 降至 0.87，即 13% 的视觉幻灯片在评分竞争中因无视觉加成被淘汰。这证明视觉丰富度因子是视觉钉扎机制的必要补充：虽然钉扎机制直接保护全部含视觉的幻灯片，但在少数边界情形（如组内竞争激烈、视觉页恰好处于角色权重较低的位置）下，评分层面的视觉加成为其提供了额外的保护缓冲。

**去除内容密度因子**（$C=0$）对 NRL 影响相对较小（-1.8），但 CRR 从 74.8% 降至 70.5%（-4.3 pp），说明该因子主要作用于信息量的保留而非叙事覆盖——内容稀疏的页面在无内容密度加成时更易被保留（因得分差异缩小），导致信息冗余页挤占了高密度页的空间。

**完整公式**在三项指标上达到最优或接近最优的平衡点（VRR = 1.00，NRL = 38.9，CRR = 74.8%），验证了三因子的共同必要性。

### 3.4.3.3 目标页数鲁棒性测试

在 Narr-Val（25 篇）上测试不同目标页数 `target_n`（10–24）下系统的页数偏差（SCD）和硬约束满足率（HCS）变化趋势，关键观察如下：

- 当 `target_n < 11`（地板约束之和 $\sum \text{GROUP\_FLOOR} = 11$）时，系统自动将有效目标提升至 11，SCD 随之增大但 HCS 保持 100%。这体现了 3.3 节提出的"最小破坏原则"：宁可增加少量页数，也不打破叙事完整性的硬约束。
- 在 `target_n` 为 15–18 的区间内，HCS = 100%、SCD 均值为 0.9，为系统最佳工作区间。该区间与参照演示文稿的页数均值（21.3 张）在同一量级，符合学术演讲 15–20 分钟的典型时长预期。
- `target_n > 22` 时，SCD 开始增大（候选池幻灯片总数约为 34.6，当目标接近候选池规模时压缩空间收窄），但 HCS 保持 100% 不变。

上述测试表明，叙事重排算法对目标页数参数具有良好的鲁棒性：在宽泛的参数范围内（11–22），硬约束满足率始终为 100%，页数偏差控制在 1 页以内。

## 3.4.4 SIR 结构质量评估

前两节分别验证了文档解析模块和叙事重构模块的独立效能。本节从 SIR（Slide Intermediate Representation）的整体结构质量出发，评估系统输出的中间表示在叙事骨架完整度、角色覆盖率、视觉保留率等维度上的综合表现，并通过典型案例可视化展示完整的演示叙事结构。

### 3.4.4.1 叙事骨架完整度与叙事组顺序分析

SIR 结构质量的首要衡量标准是**叙事骨架是否完整**——即生成的演示文稿是否保留了说服弧所需的全部 7 个叙事阶段。表 3-16 报告了各方法的叙事骨架完整度（NSI）和叙事组顺序一致率（NGOC，以 Kendall-τ 衡量）。

**表 3-16　叙事骨架完整度与顺序一致率（Narr-Val，N = 25）**

| 方法               | NSI ↑    | Kendall-τ ↑ | 叙事组顺序符合率 |
| ------------------ | -------- | ----------- | ---------------- |
| BL-1（顺序截断）   | 0.72     | 0.38        | 32%              |
| BL-2（无重排压缩） | 0.94     | 0.39        | 36%              |
| BL-3（无锚点）     | 0.96     | **0.91**    | 88%              |
| **Ours**           | **1.00** | **0.91**    | **92%**          |

**分析：**

BL-1 的 NSI 仅为 0.72，意味着平均有 2 个叙事组在截断后完全缺失——通常是位于论文末尾的 evidence 组和 closing 组，因为顺序截断优先保留了论文开头的章节。BL-2 通过组内压缩和地板约束将 NSI 提升至 0.94，但仍有个别样本中候选幻灯片未覆盖 related 组（源论文将相关工作嵌入 introduction，未形成独立章节），导致组整体缺失。

本方法达到 NSI = 1.00（全部 25 篇论文的 7 个叙事组均非空），验证了地板约束 + 锚点补位机制的双重保障足以确保叙事骨架在任何压缩条件下保持完整。

Kendall-τ 方面，BL-1 与 BL-2 的值均约为 0.38–0.39，接近完全随机排列的理论期望值 0.33，印证了 IMRAD 论文结构与 Monroe 说服弧之间存在本质性的结构差异。SciDuet 数据集的研究也报告了类似发现：约 38.6% 的演示文稿叙事顺序与源论文存在非线性关系。本方法通过 Pass 3 的跨组重排将 Kendall-τ 提升至 0.91，叙事组顺序符合率达到 92%。剩余 8% 的不一致主要集中在 related 组——部分论文的相关工作内容被作者直接嵌入 introduction 章节，解析后未形成独立的 related 组，导致该叙事位置被跳过。

## 3.4.5 本节小结

本节通过模块级评测、消融实验和 SIR 结构质量综合评估，系统验证了第三章所提方法的有效性。主要结论如下：

1. **Markdown + JSON 双路径解析**在章节召回率（96.4%）和图表归属准确率（91.3%）上显著优于纯 Markdown 路径，验证了利用 MinerU 结构化输出进行精确解析的必要性。

2. **三阶段叙事重构算法**相对顺序截断基线在角色覆盖率（+0.38）、视觉保留率（+0.51）和叙事 ROUGE-L（+10.6）上均有大幅提升，消融实验进一步证明了 `keep_score` 函数三个因子各有不可替代的独立贡献。

3. **SIR 结构质量评估**表明，系统生成的幻灯片中间表示在叙事骨架完整度（NSI = 1.00）、视觉保留率（VRR = 1.00）和硬约束满足率（HCS = 100%）上达到理论最优，角色覆盖率（0.89）和信息密度均衡度（0.87）与参照标准高度接近。

4. **案例分析**可视化展示了两篇不同领域论文（NLP 与 CV）的完整 SIR 输出结构，验证了本方法对不同论文类型的适应性。同时，理论密集型论文的失败案例分析揭示了 method 组配额饱和的局限性，指出了参数适配层面的改进方向。

5. 方法的主要局限在于**理论密集型论文的页数预算分配**和**大纲规划阶段的信息保真度**，前者可通过参数调整缓解，后者有待上游 LLM 模块的持续优化。
