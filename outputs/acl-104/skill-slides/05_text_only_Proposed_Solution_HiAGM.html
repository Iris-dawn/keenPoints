Proposed Solution: Hi-AGM

Graph-Based Hierarchy

Formulate the hierarchy as a directed graph with prior probabilities of label dependencies

Edge weights encode top-down and bottom-up conditional probabilities derived from training corpus

Captures fine-grained label correlations across the entire taxonomy

Hierarchy-Aware Structure Encoders

Introduce Hi-AGM with dedicated hierarchy-aware structure encoders

TreeLSTM: bidirectional Tree-LSTM operating top-down and bottom-up through the hierarchy

Hierarchy-GCN: graph convolutional network with gated aggregation over directed edges

Two Model Variants

HiAGM-LA (inductive): multi-label attention extracts label-wise text features using hierarchy-aware label embeddings

HiAGM-TP (deductive): propagates text features directly through the hierarchy via structure encoder

Both variants aggregate hierarchy-aware features for final multi-label classification
