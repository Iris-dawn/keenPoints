Two Model Variants: LA and TP

VARIANT A · INDUCTIVE
HiAGM-LA
Multi-Label Attention

Inductive approach with multi-label attention and hierarchy-aware label representations

Updates label embeddings using hierarchical structure encoder output

VARIANT B · DEDUCTIVE
HiAGM-TP
Text Propagation

Deductive approach with direct text feature propagation through hierarchy

Propagates textual information through taxonomic hierarchy for richer label features

⚙ Both variants extract hierarchy-aware text features using structure encoders (BiTreeLSTM or Hierarchy-GCN) for final multi-label classification.
