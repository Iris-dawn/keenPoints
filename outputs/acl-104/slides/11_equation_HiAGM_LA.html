HiAGM-LA: Label Attention Mechanism

Inductive Variant

Document processed through bidirectional GRU for contextual features

Multiple CNNs generate n-gram features with top-k max-pooling

Output: continuous text representation $\boldsymbol{S}$ with dimension $d_c$

Uses multi-label attention across hierarchy levels

Learns label representations with bidirectional hierarchical information

Computes label-wise attention values for informative text features

Produces label-aligned text features $\boldsymbol{v}_k$ for classifier input

Eq. (5) — Multi-Label Attention
$$\alpha_{kj} = \frac{e^{\boldsymbol{s}_j \boldsymbol{h}_k^T}}{\displaystyle\sum_{j=1}^{n} e^{\boldsymbol{s}_j \boldsymbol{h}_k^T}}, \qquad \boldsymbol{v}_k = \sum_{i=1}^{n} \alpha_{ki}\, \boldsymbol{s}_i$$
$\alpha_{kj}$: attention weight of token $j$ for label $k$
$\boldsymbol{h}_k$: hierarchy-aware label embedding for label $k$
$\boldsymbol{s}_j$: text feature vector for token $j$
$\boldsymbol{v}_k$: label-aligned text representation used for predicting label $k$
Text Features $\boldsymbol{S}$Bi-GRU + CNN
Label Embed $\boldsymbol{h}_k$Structure Encoder
Attention $\alpha_{kj}$Softmax dot-product
Output $\boldsymbol{v}_k$Label-aligned repr.
