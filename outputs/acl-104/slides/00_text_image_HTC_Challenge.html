Hierarchical Text Classification Challenge

Background
Text classification is widely used in NLP applications like sentiment analysis and document categorization.
Problem Definition
Hierarchical Text Classification (HTC) is a multi-label problem where categories follow a taxonomic hierarchy — labels are interdependent across levels.
Structure Representation
The taxonomy is modeled as a tree or directed acyclic graph (DAG), enabling single-path or multi-path label assignments (Figure 1).
