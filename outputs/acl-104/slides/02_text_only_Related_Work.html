Related Work in HTC

📌 Local Approaches

Includes LCN (per node), LCPN (per parent), and LCL (per level) classifiers

LCN transfers parameters of the parent model for child models

LCL combined with global optimizations alleviates exposure bias

Text-GCN decomposes the hierarchy into subgraphs for classification

🌐 Global Approaches

Enhance flat MLC models by incorporating hierarchy information

Includes Hierarchical-SVM, recursive regularization, and deep learning architectures

Seq2seq, meta-learning, and capsule networks focus on hierarchical path constraints

HiAGM introduces hierarchy-aware global modeling with label-wise text features

🔍 Attention Mechanisms

Attention mechanisms introduced in MLC for tasks like ICD coding

GraphCNN trains label representation and conducts multi-label attention

AttentionXML converts MLC to a multi-label attention LCL model

HiAGM-LA employs multi-label attention with a simplified structure encoder
