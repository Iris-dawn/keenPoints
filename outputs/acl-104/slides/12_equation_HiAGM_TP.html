HiAGM-TP: Text Propagation Through Hierarchy

Core Mechanism

Directly feeds text features into hierarchy encoders (deductive approach)

Uses linear transformation $\boldsymbol{M}$ to align text features with label structure

Characteristics

Propagates textual information through taxonomic hierarchy via structure encoder

Higher computational complexity but easier convergence than HiAGM-LA

Eq. (6) — Text Feature Transformation
$$\boldsymbol{V} = \boldsymbol{M}\boldsymbol{S}$$
$\boldsymbol{S}$: continuous text representation from CNN (shape: $n \times d_c$)
$\boldsymbol{M}$: trainable linear transformation matrix
$\boldsymbol{V}$: node input matrix for structure encoder (shape: $|L| \times d_l$)

HiAGM-LAuses attention to extract label-wise features from $\boldsymbol{S}$
HiAGM-TPprojects $\boldsymbol{S}$ via $\boldsymbol{M}$ then propagates through hierarchy
