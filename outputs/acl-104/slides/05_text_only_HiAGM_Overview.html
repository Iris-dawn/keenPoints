Hierarchy-Aware Global Model Overview

Framework Design

Leverages fine-grained hierarchy information for text classification

Addresses limitations of previous global models by integrating label correlations

Core Components

Consists of traditional text encoder and hierarchy-aware structure encoder

Aggregates label-wise text features through hierarchical correlations

Two Variants

HiAGM-LA (parallel/inductive) and HiAGM-TP (serial/deductive)

Combines text classification model with hierarchy encoder for mutual interaction
