Hierarchy-Aware Structure Encoder

Tree-LSTM Design

Tree-LSTM and GCN used as structure encoders for hierarchical label dependencies

HiAGM models hierarchy using directed graph with fine-grained prior information

Top-down dataflow uses prior hierarchy information with edge weights

Bottom-up dataflow employs uniform edge weights

Combines child-sum and top-down modules for bidirectional processing

Predefined hierarchy enables mini-batch training

Hidden states concatenated: $\boldsymbol{h}_k^{bi} = \boldsymbol{h}_k^{\uparrow} \oplus \boldsymbol{h}_k^{\downarrow}$

Eq. — Cell State Update (Tree-LSTM)
$$\boldsymbol{c}_k = \boldsymbol{i}_k \odot \boldsymbol{u}_k + \sum_j \boldsymbol{f}_{k,j} \odot \boldsymbol{c}_j$$
$\boldsymbol{i}_k$: input gate; $\boldsymbol{f}_{k,j}$: forget gate weighted by edge feature; $\boldsymbol{c}_j$: child cell states
Eq. — Hidden State Output
$$\boldsymbol{h}_k = \boldsymbol{o}_k \odot \tanh(\boldsymbol{c}_k)$$
Output gate $\boldsymbol{o}_k$ modulates flow from memory cell $\boldsymbol{c}_k$
Eq. — Bidirectional Representation
$$\boldsymbol{h}_k^{bi} = \boldsymbol{h}_k^{\uparrow} \oplus \boldsymbol{h}_k^{\downarrow}$$
$\uparrow$: bottom-up pass; $\downarrow$: top-down pass; $\oplus$: concatenation
