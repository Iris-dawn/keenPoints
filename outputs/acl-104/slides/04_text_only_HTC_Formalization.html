Formal Definition of HTC

📌 Problem Context

HTC is a subtask of text classification with a predefined taxonomic hierarchy over label space.

Hierarchy organizes labels based on class relations, capturing semantic dependencies between categories.

Two main structural forms: tree-like hierarchy and DAG (directed acyclic graph) — DAGs are convertible to tree form.

🔗 Graph Representation

Taxonomic hierarchy is represented as a directed graph:

G = (V, E)
V — set of label nodes (categories)
E — directed edges encoding top-down and bottom-up hierarchy paths

Edges in E encode both parent→child (top-down) and child→parent (bottom-up) structural relationships.

📐 Formal Mapping

HTC task is formally defined as:

H = (X, L)
X — set of text objects (input samples)
L — set of hierarchical label sets

Each sample xi ∈ X corresponds to a label set li ⊆ V, covering one or more sub-paths in the hierarchy.

Parent–child relationships enforce label inheritance: assigning a child label implies all ancestor labels are also assigned.
