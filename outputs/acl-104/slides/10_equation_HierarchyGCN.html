Hierarchy-GCN Implementation

GCN-Based Hierarchy Encoder

Aggregates dataflows through top-down, bottom-up and self-loop edges

Uses weighted adjacent matrix for hierarchical probabilities

Simplifies edge-wise transformations with weighted adjacency — efficient computation

Output hidden state represents label with full structural information

Eq. (4) — Hierarchy-GCN Node Update
1
$$\boldsymbol{u}_{k,j} = a_{k,j}\boldsymbol{v}_j + \boldsymbol{b}_l^k$$
Weighted neighbor feature: $a_{k,j}$ = hierarchy-aware edge weight; $\boldsymbol{v}_j$ = neighbor embedding
2
$$\boldsymbol{g}_{k,j} = \sigma\!\left(\boldsymbol{W}_g^{d(j,k)}\boldsymbol{v}_k + \boldsymbol{b}_g^k\right)$$
Edge-direction gate: $d(j,k)$ encodes relation direction (top-down / bottom-up)
3
$$\boldsymbol{h}_k = \mathrm{ReLU}\!\left(\sum_{j\in N(k)} \boldsymbol{g}_{k,j} \odot \boldsymbol{u}_{k,j}\right)$$
Aggregation over all neighbors $N(k)$ with gated element-wise products
