Classification and Loss Functions

Multi-Label Classification

All hierarchy nodes treated as leaf nodes for multi-label classification

Final hierarchy-aware features fed into a fully connected layer for prediction

HiAGM is complementary with recursive regularization for parameter optimization

L_total = L_cls + λ · L_reg
λ: weighting factor balancing classification and regularization losses
Loss Components

Recursive regularization ensures parameter consistency across hierarchy levels

Binary cross-entropy loss used for multi-label classification objective

Final loss combines classification and regularization with weighting factor λ

L_cls = BCE(ŷ, y)  |  L_reg = ||W_c − W_p||²
BCE: binary cross-entropy; W_c/W_p: child/parent classifier parameters
