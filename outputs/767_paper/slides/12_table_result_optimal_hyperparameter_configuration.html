Table 5: Seq2Seq with copy mechanism : Hyperparameters for the best model.

Table 5 presents the hyperparameters of the best-performing sequence-to-sequence model with a copy mechanism used for generating To-Do items from emails. Key architectural choices include an LSTM-based encoder-decoder with a single layer and 256 hidden units, word embeddings initialized using Glove vectors (100-dimensional), and a separate vocabulary for source and target sequences to improve performance and avoid overfitting. Training was conducted with a batch size of 64, Adagrad optimizer at a learning rate of 0.15, and gradient clipping set to a maximum norm of 2.0. Dropout and attention dropout were both set to 0.5 to regularize the model. The tokenizer used was spaCy, and early stopping was applied with a patience of 5 epochs based on validation token accuracy or perplexity. Beam search with width 5 was used during inference. These settings reflect a carefully tuned configuration that balances model capacity, training stability, and generalization for the task of email-based To-Do generation.
